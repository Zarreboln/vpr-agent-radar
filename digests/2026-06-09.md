## 方向一：VPR / 视觉位置识别 / 图像地理定位（14 篇）

**GeoBridge: A Semantic-Anchored Multi-View Foundation Model Bridging Images and Text for Geo-Localization**
- 作者：Zixu Song, Jing Zhang, Di Wang 等
- arXiv：[2512.02697](https://arxiv.org/abs/2512.02697)（2025-12，CVPR 2026）
- 提出跨无人机、街景、卫星三视角的统一地理定位基础模型，通过文字语义锚点对齐多模态特征；构建首个大规模跨模态多视角数据集 GeoLoc（50,000+ 对，36 国）。

**ImLoc: Revisiting Visual Localization with Image-based Representation**
- 作者：Xudong Jiang, Fangjinhua Wang, Silvano Galliani, Christoph Vogel, Marc Pollefeys
- arXiv：[2601.04185](https://arxiv.org/abs/2601.04185)（2026-01-07）
- 重新审视图像特征表示在 2D/3D 视觉定位中的作用，结合深度估计与高效匹配策略实现高精度与低内存占用的平衡。

**Thinking with Map: Reinforced Parallel Map-Augmented Agent for Geolocalization**
- 作者：Yuxiang Ji 等
- arXiv：[2601.05432](https://arxiv.org/abs/2601.05432)（2026-01-08）
- 将地图推理注入大型视觉语言模型，设计 Agent-in-the-Map 强化学习循环与并行测试时缩放，在 MAPBench 上显著领先。（HuggingFace 170 赞）

**SpotAgent: Grounding Visual Geo-localization in Large Vision-Language Models through Agentic Reasoning**
- 作者：Furong Jia, Ling Dai, Wenjin Deng, Fan Zhang, Chen Hu, Daxin Jiang, Yu Liu
- arXiv：[2602.09463](https://arxiv.org/abs/2602.09463)（2026-02）

**Automatic Map Density Selection for Locally-Performant Visual Place Recognition**
- 作者：QUT Centre for Robotics 团队
- arXiv：[2602.21473](https://arxiv.org/abs/2602.21473)（2026-02）

**Altitude-Aware Visual Place Recognition in Top-Down View**

**QdaVPR: A Novel Query-Based Domain-Agnostic Model for Visual Place Recognition**
- 作者：Shanshan Wan, Lai Kang, Yingmei Wei, Tianrui Shen, Haixuan Wang, Chao Zuo

**Locatability-Guided Adaptive Reasoning for Image Geo-Localization with Vision-Language Models**

**Evaluation of Visual Place Recognition Methods for Image Pair Retrieval in 3D Vision and Robotics**

**GeoRouter: Dynamic Paradigm Routing for Worldwide Image Geolocalization**

- 针对具身视觉地理定位提出综合评测基准，在单视图、全景视图和具身视图三种递进设置下评估 MLLM，包含 2207 个全球分布街景全景图，测量感知、空间意识、常识推理与地理定位推理四维能力；发现当前模型在细粒度感知与跨视图空间一致性上仍有明显差距。方向一（VPR / 地理定位评测）。

### 方向二：Agent 做检索（Agentic RAG）（+1 篇）

**MARDoc: A Memory-Aware Refinement Agent Framework for Multimodal Long Document QA**
- 作者：Kaifeng Chen 等（天津大学、奇富科技、北京航空航天大学、江南大学）
- arXiv：[2606.05749](https://arxiv.org/abs/2606.05749)（2026-06-04）
- 热度：`[预印本]`
- 提出记忆感知多智能体框架，将长文档 QA 解耦为 Explorer（多粒度多模态检索）、Refiner（交互轨迹→结构化证据记忆）和 Reflector（证据充分性检查与反馈）三个专项智能体；以动态结构化记忆替代累积上下文，降低多跳推理噪声，在 MMLongBench-Doc 和 DocBench 上取得提升。方向二（Agentic RAG）兼涉方向三（多模态检索智能体）。

### 方向四：Agent 做细粒度检索（ZS-CIR with Multi-Agents）（+1 篇）

**Matching with Deliberation: Test-Time Evolutionary Hierarchical Multi-Agents for Zero-Shot Compositional Image Retrieval**
- 作者：Xingtian Pei, Yukun Song, Changwei Wang, Shunpeng Chen, Rongtao Xu, Shibiao Xu
- arXiv：[2605.22478](https://arxiv.org/abs/2605.22478)（2026-05，cs.CV 本周新出现）
- 热度：`[预印本]`
- 提出层次化感知-审慎框架（PDF），含 Worker-Manager 分层系统；意图感知先验路由（IPR）自适应分配多视角检索权重以缓解语义漂移；进化推理精炼器（ERR）引入经验驱动的测试时缩放策略，无需训练即在 FashionIQ、CIRR、CIRCO 等基准上取得强性能。方向四（细粒度检索 + 多智能体）。
