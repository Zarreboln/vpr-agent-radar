## 方向2：Agent 做检索 / Agentic RAG / LLM-Agent Retrieval

### 1. PaperSearchQA: Learning to Search and Reason over Scientific Papers with RLVR

**PaperSearchQA: Learning to Search and Reason over Scientific Papers with RLVR**
作者：James Burgess, Jan N. Hansen, Duo Peng, Yuhao Zhang, Alejandro Lozano, Min Woo Sun, Emma Lundberg, Serena Yeung-Levy
arXiv:[2601.18207](https://arxiv.org/abs/2601.18207)(2026-01-26,EACL 2026)
热度标签：`[EACL 2026 | HF▲19]`
构建了基于生物医学论文摘要的 QA 训练语料（PaperSearchQA），利用 RLVR（Reinforcement Learning with Verifiable Rewards）训练搜索 agent 在科学文献上做多步检索与推理，在 BioASQ 上泛化良好，展示了用 RL 训练文献检索 agent 的可行路径。
归属方向：方向2（Agent做检索）

### 2. Harness-1: Reinforcement Learning for Search Agents with State-Externalizing Harnesses

**Harness-1: Reinforcement Learning for Search Agents with State-Externalizing Harnesses**
作者：Pengcheng Jiang, Zhiyi Shi, Kelly Hong, Xueqiang Xu, Jiashuo Sun, Jimeng Sun, Hammad Bashir, Jiawei Han
arXiv:[2606.02373](https://arxiv.org/abs/2606.02373)(2026-06-01)
热度标签：`[HF▲54 | GitHub: pat-jj/harness-1]`
将搜索 agent 的 bookkeeping（候选池、证据链接、验证记录、预算感知上下文渲染）外化给 harness 环境维护，RL 只优化语义决策而非 bookkeeping；20B 模型在困难检索任务上匹配甚至超过多个更大的前沿搜索系统。
归属方向：方向2（Agent做检索）

### 3. Chaining the Evidence: Robust Reinforcement Learning for Deep Search Agents with Citation-Aware Rubric Rewards

**Chaining the Evidence: Robust Reinforcement Learning for Deep Search Agents with Citation-Aware Rubric Rewards**
作者：Jiajie Zhang, Xin Lv, Ling Feng, Lei Hou, Juanzi Li（清华大学 & 智谱 AI）
arXiv:[2601.06021](https://arxiv.org/abs/2601.06021)(2026-01-09)
热度标签：`[HF▲48 | GitHub: THUDM/CaRR]`
提出 CaRR（Citation-aware Rubric Rewards）细粒度奖励框架，将复杂问题分解为可验证的单跳 rubrics，要求 agent 通过引用显式满足每条 rubric 并构建完整证据链，C-GRPO 算法有效抑制 shortcut 行为与幻觉，在多个 deep search 基准上超越标准 outcome-based RL。
归属方向：方向2（Agent做检索）

### 4. DeepResearch-9K: A Challenging Benchmark Dataset of Deep-Research Agent

**DeepResearch-9K: A Challenging Benchmark Dataset of Deep-Research Agent**
作者：Tongzhou Wu, Yuhao Wang, Xinyu Ma, Xiuqiang He, Shuaiqiang Wang, Dawei Yin, Xiangyu Zhao
arXiv:[2603.01152](https://arxiv.org/abs/2603.01152)(2026-03-01)
热度标签：`[HF▲未知]`
发布 9K 规模的 deep research agent 挑战性基准，覆盖需要多步 web 探索的复杂 QA；同时提供开源训练框架与 LLM-as-judge 奖励机制，针对现有 deep research agent 的瓶颈提供系统性评测与训练支撑。
归属方向：方向2（Agent做检索）

## 方向4：Agent 做细粒度检索 / Fine-Grained Image Retrieval with LLM/Agents

### 5. MCoT-MVS: Multi-level Vision Selection by Multi-modal Chain-of-Thought Reasoning for Composed Image Retrieval

**MCoT-MVS: Multi-level Vision Selection by Multi-modal Chain-of-Thought Reasoning for Composed Image Retrieval**
作者：Xuri Ge, Chunhao Wang, Xindi Wang, Zheyun Qin, Zhumin Chen, Xin Xin（山东大学）
arXiv:[2603.17360](https://arxiv.org/abs/2603.17360)(2026-03-18,WWW 2026)
热度标签：`[WWW 2026]`
利用 MLLM 对多模态组合查询（参考图像 + 修改文本）做 chain-of-thought 推理，生成 retained/removed/target-inferred 三类文本提示，引导注意力感知的多层级视觉特征选择；在 CIRR 和 FashionIQ 基准上取得新 SOTA。
归属方向：方向4（Agent做细粒度检索）

### 6. HINT: Composed Image Retrieval with Dual-path Compositional Contextualized Network

**HINT: Composed Image Retrieval with Dual-path Compositional Contextualized Network**
作者：Mingyu Zhang, Zixu Li, Zhiwei Chen, Zhiheng Fu, Xiaowei Zhu, Jiajia Nie, Yinwei Wei, Yupeng Hu
arXiv:[2603.26341](https://arxiv.org/abs/2603.26341)(2026-03，ICASSP 2026)
热度标签：`[ICASSP 2026]`
提出 HINT 双路径组合上下文化网络，分别编码视觉路径与文本路径的上下文信息，并通过放大匹配/非匹配样本的相似度差异来提升区分度；在 FashionIQ、CIRR 等复杂场景 CIR 基准上优于同期方法。
归属方向：方向4（Agent做细粒度检索）

### 7. Do Composed Image Retrieval Benchmarks Require Multimodal Composition?

**Do Composed Image Retrieval Benchmarks Require Multimodal Composition?**
作者：Matteo Attimonelli, Alessandro De Bellis, Aryo Pradipta Gema, Rohit Saxena, Monica Sekoyan, Wai-Chung Kwan, Claudio Pomo, Alessandro Suglia 等（Politecnico di Bari、爱丁堡大学等）
arXiv:[2605.14787](https://arxiv.org/abs/2605.14787)(2026-05-15)
热度标签：`[HF▲未知]`
系统分析四个主流 CIR 基准与十一个通用多模态嵌入模型，发现 32.2%–83.6% 的查询可仅靠单一模态（图像或文本）解决，揭示现有基准中普遍存在单模态 shortcut 问题；对 CIR 评估体系的可靠性发出重要警示。
归属方向：方向4（Agent做细粒度检索）

### 8. WISER: Wider Search, Deeper Thinking, and Adaptive Fusion for Training-Free Zero-Shot Composed Image Retrieval

**WISER: Wider Search, Deeper Thinking, and Adaptive Fusion for Training-Free Zero-Shot Composed Image Retrieval**
作者：Tianyue Wang, Leigang Qu, Tianyu Yang, Xiangzhao Hao, Yifan Xu, Haiyun Guo, Jinqiao Wang（中科院自动化所、国科大、NUS 等）
arXiv:[2602.23029](https://arxiv.org/abs/2602.23029)(2026-02-26)
热度标签：`[HF▲2]`
提出无训练 ZS-CIR 框架，通过"retrieve-verify-refine"三阶段管线统一文本到图像与图像到图像两种检索范式；引入意图感知宽度搜索与不确定性感知自适应融合，在 CIRR、FashionIQ、CIRCO 上超越同类无训练方法。
归属方向：方向4（Agent做细粒度检索）
