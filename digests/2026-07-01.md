## 方向一：VPR / 视觉位置识别 / 图像地理定位

### 1. **Beyond 2D Matching: A Unified Single-Stage Framework for Geometry-Aware Cross-View Object Geo-Localization**

**作者：** Liyao Wang, Ruipu Wu, Haojun Xu, Lei Shi, Linjiang Huang, Si Liu

arXiv:[2606.30576](https://arxiv.org/abs/2606.30576)(2026-06-30，ECCV 2026)

`[ECCV 2026]`

提出统一单阶段框架，引入几何感知模块以处理跨视角（地面-卫星/无人机）的目标级地理定位任务，突破传统 2D 匹配的局限。ECCV 2026 顶会录用，是本方向首要推荐。

### 2. **EmbodiedPlace: Learning Mixture-of-Features with Embodied Constraints for Visual Place Recognition**

**作者：** Bingxi Liu, Hao Chen, Shiyi Guo, Yihong Wu, Jinqiang Cui, Hong Zhang

arXiv:[2506.13133](https://arxiv.org/abs/2506.13133)(2025-06-16)

`[热度：未知]`

针对具身场景下的视觉位置识别，学习融合多种特征（Mixture-of-Features）并引入具身约束（如机器人运动先验），提升不同数据集下跨尺度、跨场景的定位鲁棒性。

## 方向二：Agent 做检索 / Agentic RAG / LLM 检索 Agent

### 3. **AgenticRAGTracer: A Hop-Aware Benchmark for Diagnosing Multi-Step Retrieval Reasoning in Agentic RAG**

**作者：** Qijie You, Wenkai Yu, Hao Liang, Zhen Hao Wong, Wentao Zhang

arXiv:[2602.19127](https://arxiv.org/abs/2602.19127)(2026-02-22，ACL 2026 Findings)

`[ACL 2026 Findings | HF▲2]`

首个支持逐步验证的 Agentic RAG 跳数感知评测基准，覆盖 1,305 条多领域多跳数据，实验显示 GPT-5 在最难子集上 EM 精度仅 22.6%，失败根源在于推理链过早中断或过度延伸。ACL 2026 Findings 录用。

---

### 4. **MemGraphRAG: Memory-based Multi-Agent System for Graph Retrieval-Augmented Generation**

**作者：** Chuanjie Wu, Zhishang Xiang, Yunbo Tang, Zerui Chen, Qinggang Zhang, Jinsong Su

arXiv:[2606.00610](https://arxiv.org/abs/2606.00610)(2026-06-01，KDD 2026)

`[KDD 2026]`

引入基于共享记忆的多智能体协作社会，动态解决知识提取中的逻辑冲突并维护图结构连通性，并配套记忆感知层次化检索算法，在多基准测试上超越 GraphRAG 基线。KDD 2026 顶会录用。

---

### 5. **Critic-R: Improving Agentic Search using Instruction-tuned Retrievers with Natural Language Introspective Feedback**

**作者：** Md Zarif Ul Alam, Alireza Salemi, Hamed Zamani

arXiv:[2606.00590](https://arxiv.org/abs/2606.00590)(2026-05-30)

`[热度：未知]`

通过引入 Critic 模型对 Agent 内省推理轨迹进行评估，自动生成自然语言反馈以指导检索器微调，闭合了 Agentic Search 中检索模型与推理 Agent 之间的反馈回路；无需金标准标注，适合真实场景部署。
