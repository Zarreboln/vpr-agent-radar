## 方向一：VPR / 视觉位置识别 / 图像地理定位

### **GeoAgent: Learning to Geolocate Everywhere with Reinforced Geographic Characteristics**
**Modi Jin, Yiming Zhang, Boyuan Sun, Dingwen Zhang, MingMing Cheng, Qibin Hou**
arXiv:[2602.12617](https://arxiv.org/abs/2602.12617)(2026-02-13，CVPR 2026)
`[CVPR 2026 | HF▲20 | ★GitHub]`
提出 GeoSeek 数据集（由地理专家标注 CoT），结合地理相似性奖励与一致性奖励训练视觉-语言模型，使模型在全球图像地理定位中推理过程更接近人类思维，达到 CVPR 2026 最优。

---

### **Vision-Language Reasoning for Geolocalization: A Reinforcement Learning Approach (Geo-R)**
**Biao Wu, Meng Fang, Ling Chen, Ke Xu, Tao Cheng, Jun Wang**
arXiv:[2601.00388](https://arxiv.org/abs/2601.00388)(2026-01-01，AAAI 2026)
`[AAAI 2026]`
提出"Chain of Region"规则式层次化推理范式，将 GPS 坐标映射为国家→省份→城市地理实体，无需合成标注；配合基于 Haversine 距离的轻量 RL 策略，实现可解释、检索无关的全球图像地理定位。

---

### **GeoBrowse: A Geolocation Benchmark for Agentic Tool Use with Expert-Annotated Reasoning Traces**
**Xinyu Geng, Yanjing Xiao, Yuyang Zhang, Hanwen Wang, Xinyan Liu, Rui Min, Tianqing Fang, Yi R. Fung**
arXiv:[2604.04017](https://arxiv.org/abs/2604.04017)(2026-04-05)
`[HF▲8]`
包含 300 个实例（两级难度）的地理定位基准，提供结合视觉推理与知识密集型多跳查询的 GATE 工作流（9 种工具），并发布专家逐步标注的推理轨迹，用于评估 Agentic 模型的地理定位能力。

## 方向二：Agent 做检索（Agentic Retrieval / LLM-Agent Retrieval）

### **SearchSwarm: Towards Delegation Intelligence in Agentic LLMs for Long-Horizon Deep Research**
**Pu Ning, Quan Chen, Kun Tao, Xinyu Tang, Tianshu Wang, Qianggang Cao, Xinyu Kong, Zujie Wen, Zhiqiang Zhang, Jun Zhou**
arXiv:[2606.09730](https://arxiv.org/abs/2606.09730)(2026-06-08)
`[未知]`
主 Agent 将长任务分解并调度给子 Agent 执行、汇总返回，以保护主 Agent 上下文预算；通过 Harness 引导的 SFT 数据内化 Delegation Intelligence，所得 SearchSwarm-30B-A3B 在 BrowseComp 达 68.1、BrowseComp-ZH 达 73.3，同量级模型最优。

## 方向三：Agent 做图像检索（Agentic Image Retrieval / Multimodal Retrieval Agent）

### **Task-Adaptive Retrieval over Agentic Multi-Modal Web Histories via Learned Graph Memory**
**Saman Forouzandeh, Kamal Berahmand, Mahdi Jalili**
arXiv:[2604.07863](https://arxiv.org/abs/2604.07863)(2026-04，SIGIR 2026)
`[SIGIR 2026]`
面向 Agent 浏览历史中混合图文内容的检索任务，通过可学习图记忆（Learned Graph Memory）自适应地对多模态 Web 轨迹建模，在 SIGIR 2026（第 49 届 ACM SIGIR，墨尔本）发表，是 Agentic 多模态检索的首个 SIGIR 顶会工作之一。
